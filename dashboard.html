// new member gate PRO FEATURE

New members get a restricted role the instant they join — they can only see the channels you choose below — plus a DM with instructions. The role is automatically removed the moment they gain whichever role you designate as the "unlock" role in Step 3 (your verification bot's Verified role, for example) — that's what unlocks the rest of the server for them. Follow the steps below in order.

STEP 1

Create the role in Discord

Go to Server Settings → Roles → Create Role. Name it anything — "New Member" or "Unverified" both work fine. It doesn't need any permissions turned on.

⚠ Important: drag this new role so it sits below AuraAI's own role in your role list. Discord only lets a bot manage roles positioned below its own — if AuraAI's role ends up underneath this one, the bot won't be able to assign or remove it and this feature silently won't work.

STEP 2

Select that role

STEP 3

Which role(s) unlock it?

The moment a member gains ANY ONE of the roles you check below — from any source, not just AuraAI — the New Member role gets removed and they're unlocked. If you use a separate verification bot (like Double Counter), check its "Verified" role. If your Reaction Roles menu has multiple options (game roles, interest roles, etc.), you can check all of them — picking up any single one unlocks the member.

⚠ Don't check the same role selected in Step 2 — a role can't unlock itself.

STEP 4

Choose which channels new members CAN see

Every other channel gets hidden from this role until they unlock. At minimum, check your general chat and wherever your verification happens.

⚡ Switching over from Discord's native Onboarding? Click for full steps.

If your server is a Community server, Discord's built-in Onboarding question flow is probably still showing new members its own prompts alongside (or instead of) AuraAI's. Turning it off is a few clicks in Discord itself — AuraAI can't do this part for you, since it's a Discord server setting, not something a bot can toggle.

  1. In Discord, go to Server Settings → Onboarding and switch off the main Onboarding toggle at the top of that page. This turns off the built-in question flow — it does not remove your server's Community status, Rules channel, or Public Updates channel.
  2. On that same page, check the Server Guide section — it's technically part of Onboarding and can sometimes stick around after the main toggle is off. Clear or disable it too if you don't want it showing.
  3. Go to Server Settings → Overview → Welcome Screen and decide whether to keep it as a simple rules/invite display or turn it off, since AuraAI's DM flow is now doing the actual welcoming.
  4. Server Settings → Safety Setup → Verification Level is separate from Onboarding and unaffected by any of this — no changes needed there.
  5. Come back here and confirm the questions above match what you want, tell people about /onboard-me as the fallback, and you're fully switched over.

Discord's menu labels shift from time to time — if something above doesn't match exactly what you see, look for the closest match under Server Settings.

// warn threshold PRO FEATURE

Who does this affect?

Any member who receives warnings through your mods running /warn. Mods themselves are never affected by this — it only acts on the person being warned.

What does it do?

Once a member's total warning count reaches the threshold you set, AuraAI automatically times them out for the duration you set — no mod has to catch it or act manually. It fires the instant the triggering /warn is issued.

Where does it apply?

Server-wide — warning counts aren't tied to any specific channel, so it doesn't matter where the warnings were issued.

// security PRO FEATURE

Members with Manage Server or Administrator are always immune to both tools below — you'll never lock yourself out testing your own settings.

Who does this affect?

Any member without Manage Server or Administrator — so regular members and anyone posting a scam/phishing link (fake Nitro giveaways, fake payment or refund links, crypto scam invites are common targets for paid Discord communities).

What does it do?

Deletes any message containing a link to a domain on your list below. You choose how far it escalates: just delete the message, delete it and issue a formal warning (counts toward Warn Threshold above), or delete it and time the member out immediately.

Where does it apply?

Every message, in every channel, server-wide.

Who does this affect?

Any member without Manage Server or Administrator who posts in the trap channel you designate below — real members should never have a reason to post there.

What does it do?

Instantly deletes their message and punishes them — kick, ban, or timeout, your choice — with no warning first. This is meant to catch raid bots and spam accounts posting blind, not to be a "first offense" tool.

Where does it apply?

Only the one channel you pick below.

Tip for making it actually work

Name the channel something a raid bot or spam account would target but a real member never would — e.g. "free-nitro", "giveaway-claim", "verify-here" (if you're not already using that name for real verification). If you're using New Member Gate, you can also make this channel one that only the New Member role can see — real verified members will never even encounter it.
